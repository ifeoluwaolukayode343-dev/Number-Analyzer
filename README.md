# 🔢 Number Analyzer

Number Analyzer is a simple Python application built with Streamlit.

The application allows users to enter a list of numbers and automatically analyzes the numbers to provide useful information.

## 🚀 Features

The application can:

- Calculate the total sum
- Calculate the average
- Find the largest number
- Find the smallest number
- Count the number of values entered
- Identify even numbers
- Identify odd numbers

## 🛠️ Technologies Used

- Python
- Streamlit
- Git
- GitHub
- Streamlit Community Cloud
